Tokens, components, behaviour

Every value used by DocsLite Prototype 2, in the form the stack wants it: Tailwind v4 CSS-first @theme, Lucide icons, Tiptap for the canvas, sonner for toasts, next/font for the three typefaces. Light mode is primary.

@import "tailwindcss";

@theme {
  /* surfaces & ink */
  --color-bg:            #f7f8fa;   /* app background        */
  --color-surface:       #ffffff;   /* cards, sheet, sidebar */
  --color-ink:           #10131a;   /* headings, strong text */
  --color-body:          #2a3038;   /* body copy             */
  --color-muted:         #6e7681;   /* secondary text        */
  --color-faint:         #98a0ab;   /* meta, placeholders    */
  --color-line:          #e4e7eb;   /* 1px borders           */
  --color-line-soft:     #eef0f3;   /* row dividers          */

  /* brand */
  --color-accent:        #5b5bd6;
  --color-accent-hover:  #4a4ac2;
  --color-accent-press:  #4141ad;
  --color-accent-tint:   #f0f0fe;   /* active row / toggle   */
  --color-accent-line:   #d5d5f7;

  /* status */
  --color-success:       #167c4e;
  --color-danger:        #c0362c;
  --color-danger-tint:   #fdf2f1;

  /* type */
  --font-sans:   "Instrument Sans", ui-sans-serif, system-ui, sans-serif;
  --font-serif:  "Source Serif 4", Georgia, serif;   /* document canvas */
  --font-display:"Instrument Serif", Georgia, serif; /* hero moments    */

  /* radius */
  --radius-sm: 6px;    /* toolbar toggles, inline inputs */
  --radius-md: 8px;    /* buttons, fields, rows          */
  --radius-lg: 12px;   /* cards, sheet, avatars-64       */
  --radius-xl: 14px;   /* dialog                         */

  /* elevation */
  --shadow-sm: 0 1px 2px rgb(16 19 26 / .05), 0 1px 1px rgb(16 19 26 / .04);
  --shadow-md: 0 4px 14px rgb(16 19 26 / .07), 0 1px 2px rgb(16 19 26 / .05);
  --shadow-lg: 0 24px 60px rgb(16 19 26 / .18), 0 2px 8px rgb(16 19 26 / .08);

  /* motion */
  --ease-out-quint: cubic-bezier(.32,.72,0,1);
}

Spacing uses Tailwind's default 4px scale untouched. The only custom easing is --ease-out-quint, used for the dialog, the toast and the mobile drawer.

{{ rp.region }}{{ rp.desktop }}{{ rp.tablet }}{{ rp.mobile }}

The prototype drives these with @container app (max-width: …) so the frame can be resized in place; in the real app use ordinary @media / Tailwind sm: lg: breakpoints. No horizontal page scroll at any width; the formatting toolbar is the one element allowed to scroll horizontally.

07 · Accessibility & keyboard

Contrast (WCAG 2.1 AA)
Body #2A3038 on #FFFFFF — 12.6:1 · muted #6E7681 — 4.8:1 · faint #98A0AB is meta-only at ≥ 12px, never body copy · white on --accent — 5.3:1 · --danger on white — 5.1:1 · every avatar fill ≥ 4.5:1.
Keyboard
Tab through header → toolbar → canvas → sheet. Toolbar buttons are aria-pressed toggles. Dialog traps focus, Esc closes, Enter in the email field submits the share. Drawer returns focus to the hamburger on close. All icon-only buttons carry aria-label + a title tooltip.
Not colour alone
Role badges pair tint with text. Save status pairs colour with an icon and a word. Toast state is a dot and the copy. Reduced motion collapses every duration to 0.01ms. Touch targets ≥ 44×44 below 640px.
